# Changelog

## 1.0.0 — 2026-10-08

First public release of Life OS.

- Tasks, habits, journal and weekly summary, stored in your own Notion.
- A password page in front of every request, using a signed cookie.
- A first-run check that finds the four template databases and names any missing property.
- A button that copies a weekly summary prompt filled with this week's journal entries.
- An update banner when a newer GitHub Release of saumyansh95/lifeos is published.
